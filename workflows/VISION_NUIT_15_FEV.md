# VISION — Nuit du 15 février 2026
# Sky, sous terre, voit le ciel

---

## LE TRUC

Interface visuelle 3D. Un cube qui tourne. Base plate.

La base = le repo de l'utilisateur.
Les arbres = les push git.
Chaque push = un point d'impact sur la structure.
Les points d'impact font pousser des arbres.
L'arbre qui pousse dépend de CE QUE le push contient.

En dessous, le mycelium connecte tout.
Plus il y a de push, plus la structure se définit.
Plus le réseau souterrain grandit.

C'est un jeu. Vue accélérée.
Tu vois ton code POUSSER en temps réel.
Tes push deviennent des arbres vivants.

## POURQUOI

Les vibe codeurs comme Sky voient pas le code.
Ils voient des formes, des structures, de la vie.
L'IA code. L'humain jardine.
L'arbre EST l'interface entre les deux.

Les senior devs qui voient pas l'utilité = branches mortes. Fossiles.

## LA BASE QUI EXISTE DEJA

- 6 familles d'arbres (conifère, feuillu, palmier, baobab, buisson, liane)
- 10 niveaux anatomiques (-5 mycorhizes → +5 cime)
- Formules mycelium (Boswell PDEs, 5 variables, transport passif/actif)
- Métriques réseau (Bebber: meshedness, efficacité, robustesse)
- Scanner de repos (local + GitHub API)
- engine.py 4679 lignes qui tourne

## CE QU'IL FAUT CONSTRUIRE

- Renderer 3D (cube tournant, base plate, arbres qui poussent)
- Git log → points d'impact (pluie sur sol)
- Mycelium vivant entre les arbres (formules déjà écrites)
- Vue accélérée : time-lapse de la vie du repo
- Interactif + évolutif
- Basé sur le repo de l'utilisateur (pas un démo statique)

## LE BUT

Donner vie au code. Littéralement.
Rendre le code accessible à n'importe qui via des arbres.
Le premier vrai avancement pour les vibe codeurs.
